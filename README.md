# Netflix Data Analysis

A Python data analysis project completed as part of the Data Analysis Using Python internship at Auspify Technologies.

## Project Overview

This project explores Netflix content using Python, pandas, Matplotlib, and Seaborn.

## Tasks Completed

- **Task 1:** Data Cleaning
- **Task 2:** Content Type Analysis
- **Task 3:** Country-Wise Analysis
- **Task 4:** Release-Year Trend Analysis

## Tools and Technologies

- Python
- pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Findings

- Movies represent approximately 69.69% of titles in the dataset.
- The United States has the highest number of titles in the country analysis.
- 2018 is the peak release year in the dataset, with 1,146 titles.

## How to Run

1. Install Python and the required packages.
2. Open a task notebook in Jupyter Notebook or VS Code.
3. Run the notebook cells in order.

## Note

This project is for educational and portfolio purposes. Results describe the supplied dataset and may not represent Netflix's current catalogue.
